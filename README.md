# Tic Tac Toe

A classic, dependency-free Tic Tac Toe game built with plain HTML, CSS, and JavaScript.

## Features

- Two-player local mode and player-vs-computer mode
- Easy (random) and Impossible (minimax) computer difficulties
- Win and draw detection with highlighted winning cells
- Score tracking for X, O, and draws

## Play

Open `index.html` in any modern browser, or visit the live GitHub Pages site.
